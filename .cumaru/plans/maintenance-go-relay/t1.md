# T1 — `session.ClaudeBin` + `nudge.RingClaude`

## What to do

- `session.ClaudeBin(home) string`: `exec.LookPath("claude")`, else
  `home/.local/bin/claude`; `ClaudeAgents` uses it (DRY: the second caller of
  the same lookup arrives in T2).
- `go/internal/nudge/claude.go`: `RingClaude(bin, home, name, prompt string) error`
  - returns nil without spawning when `bin` is not an executable regular file;
  - picks a random v4 UUID `rid`;
  - starts `/bin/sh -c '"$1" -p --session-id "$2" --name "$3" --model claude-haiku-4-5-20251001 --effort low --allowedTools=SendMessage <prompt-from-$4 >/dev/null 2>&1; rm -f "$5"'`
    with every value positional, `Dir = home/.claude`, `Setsid`, stdio nil,
    and releases the process without waiting;
  - `$5` is exactly `home/.claude/projects/<home/.claude with / and . as ->/<rid>.jsonl`.

## Context

Bash `relay()` (`alter-bridge:382-395`). Bash detaches with `( ... ) &`; a Go
process cannot leave its own code running after exit, so the shell holds the
wait-then-remove sequence. The prompt travels as an argument and reaches
`claude` on stdin through `printf`, so nothing depends on the Go process
staying alive to feed a pipe.

## Implementation

1. Tests first with a fake builtins-only `claude` script (records argv, `pwd`,

   record: argv/cwd/stdin exact, transcript removed, a sibling transcript
   kept; non-executable or missing bin spawns nothing; `ClaudeBin` finds PATH
   then the fallback.
