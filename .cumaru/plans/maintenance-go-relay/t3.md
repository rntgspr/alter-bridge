# T3 — Live verification against a disposable Claude session (user-run)

## What to do

Run the steps in `## Implementation

Isolation: the probe uses its own root (`~/.alter-bridge-probe`), so the
global bash hooks (still wired to `~/.alter-bridge`) see every probe event as
"outside root" and stay silent.

1. Build: `cd ~/agentic-workspace/papa/alter-bridge/go && go build -o ~/.local/share/ab-probe ./cmd/alter-bridge`; set `AB=~/.local/share/ab-probe`.
2. Make a scratch project inside the workspace, e.g. `mkdir -p ~/agentic-workspace/papa/relay-probe/.claude`, and write `~/agentic-workspace/papa/relay-probe/.claude/settings.local.json` with two hooks (project-local only; do not touch `~/.claude/settings.json`):
   - `SessionStart`: `ALTER_BRIDGE_ROOT=$HOME/.alter-bridge-probe $AB watchpaths claude:relay-probe`
   - `FileChanged`: `ALTER_BRIDGE_ROOT=$HOME/.alter-bridge-probe $AB relay claude:relay-probe`
3. Start `claude` in that directory, `/rename relay-probe`, exit, and resume it (`claude --resume`) so `SessionStart` registers the watch under the probe root with the session already named. Confirm `~/.alter-bridge-probe/claude/relay-probe/` exists.
4. Leave it idle. From another shell: `printf 'live relay probe\n' | ALTER_BRIDGE_ROOT=$HOME/.alter-bridge-probe $AB send claude:relay-probe --from claude:papa`.
5. Expect in the probe session: a `systemMessage` `alter-bridge: new message from claude:papa (msgid ...)` and the session woken by the `SendMessage` ring (the next turn drains nothing, since only the bash `hook` is wired; `ALTER_BRIDGE_ROOT=$HOME/.alter-bridge-probe $AB peek claude:relay-probe` shows the message). `tail -1 ~/.alter-bridge-probe/.tmp/relay.log` shows the `add` payload.
6. Expect no leftover relay after ~1 min: no new `<uuid>.jsonl` in `~/.claude/projects/$(printf %s "$HOME/.claude" | tr '/.' '--')/`, and `claude agents` lists no `relay-claude-papa`.
7. Watcher-death check: repeat step 4 after the probe has sat idle for a few hours. If nothing rings, the last `relay.log` line tells watcher death (no new entry) from relay failure (entry present, no ring).
8. Clean up: close the probe, `rm -rf ~/agentic-workspace/papa/relay-probe ~/.alter-bridge-probe ~/.local/share/ab-probe`.
