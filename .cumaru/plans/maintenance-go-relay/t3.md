# T3 — Live verification against a disposable Claude session (user-run)

## What to do

Run the steps in `## Implementation` yourself (Renato). An agent MUST NOT run
them: they spawn a real `claude -p` and wake a real session.

## Context

AC8 / Risks: the `FileChanged` watcher-death class of bug and the real
`SendMessage` ring cannot be reached by tests with fake binaries.

## Implementation

1. Build: `cd go && ./build.sh` (or `go build -o /tmp/ab-go ./cmd/alter-bridge`); note the binary path `$AB`.
2. Start a disposable Claude session inside `~/agentic-workspace/<agent>` and `/rename` it to `relay-probe`.
3. In that session only, add a project-local hook (`.claude/settings.local.json` of a scratch dir, not the global settings) replacing the bash `FileChanged` command with `$AB relay claude`, and the `SessionStart` one with `$AB watchpaths claude`; restart the session so `watchPaths` registers.
4. Leave it idle. From another shell: `$AB send claude:relay-probe --from claude:papa <<<'live relay probe'`.
5. Expect: a `systemMessage` "alter-bridge: new message from claude:papa (msgid ...)" in the probe session, and the session woken by the `SendMessage` ring; `tail -1 ~/.alter-bridge/.tmp/relay.log` shows the `add` payload.
6. Expect no leftover relay: `ls ~/.claude/projects/-Users-$USER--claude/` has no new `<uuid>.jsonl` after ~1 min, and `claude agents` shows no lingering `relay-claude-papa`.
7. Repeat step 4 after the session has sat idle for a few hours; if nothing rings, the last `relay.log` entry tells watcher death (no entry) from relay failure (entry present).
8. Remove the local hook override and close the probe session.

## Done when

- [ ] Steps 5 and 6 observed (PASS) and recorded in `handoff-t3.md`; step 7 outcome noted.
