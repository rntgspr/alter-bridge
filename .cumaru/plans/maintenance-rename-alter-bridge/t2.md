# T2 — Rename skill directory, CLI script, and SKILL.md

## What to do

Move `skills/agent-bridge/` to `skills/alter-bridge/`, rename the CLI script
from `agent-bridge` to `alter-bridge`, and update every command/path
reference inside `SKILL.md`.

## Context

The script lives at `skills/agent-bridge/scripts/agent-bridge` (466 lines
bash) and is deliberately off `PATH` — callers invoke it by absolute path.
`SKILL.md` documents that absolute path plus dozens of `agent-bridge <sub>`
command examples that need the new binary name. `install-hooks.sh` in the
same `scripts/` dir resolves the bridge script by relative path
(`here="$(cd "$(dirname "$0")" && pwd)"; bridge="$here/agent-bridge"`) —
that line is T3's job, not this one, but T2 must not break it mid-move.

## Implementation

1. `git mv skills/agent-bridge skills/alter-bridge`.
2. `git mv skills/alter-bridge/scripts/agent-bridge skills/alter-bridge/scripts/alter-bridge`.
3. In `skills/alter-bridge/SKILL.md`: frontmatter `name: agent-bridge` -> `name: alter-bridge`; every `agent-bridge <sub>` example and the absolute path in the `Command:` line -> `alter-bridge`.
4. Do not touch `AGENT_BRIDGE_ROOT` or `~/.agent-bridge` references in `SKILL.md` yet — T3 owns those.
