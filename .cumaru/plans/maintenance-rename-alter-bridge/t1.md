# T1 — Rename plugin manifests

## What to do

Rename the plugin identity in both manifests, including `repository`.

## Context

`plugin.json` (Codex) and `.claude-plugin/plugin.json` (Claude) both carry
`"name": "agent-bridge"`, a `description` mentioning `~/.agent-bridge/`, and
`repository` pointing at `https://github.com/rntgspr/agent-bridge`. The
GitHub repo has already been renamed to `rntgspr/alter-bridge` and this
checkout's `origin` remote was repointed ahead of this plan.

## Implementation

1. In both files, set `"name": "alter-bridge"`.
2. Update `description` to say `~/.alter-bridge/` instead of `~/.agent-bridge/`.
3. In both files, update `repository` to `https://github.com/rntgspr/alter-bridge`.

## Done when

- [ ] `grep -n '"name"' plugin.json .claude-plugin/plugin.json` shows `alter-bridge` in both.
- [ ] `grep -n agent-bridge plugin.json .claude-plugin/plugin.json` returns nothing.
- [ ] `grep -n alter-bridge plugin.json .claude-plugin/plugin.json` shows `name`, `description`, and `repository` all updated.
