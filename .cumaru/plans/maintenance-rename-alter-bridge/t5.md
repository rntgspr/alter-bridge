# T5 — Migrate live mailbox and reinstall this machine's hooks

## What to do

Move the live mailbox from `~/.agent-bridge` to `~/.alter-bridge` without
losing pending or archived messages, then reinstall the Claude/Codex hooks
so they point at the renamed script.

## Context

`~/.agent-bridge` currently holds live `claude/`, `codex/`, and `.archive/`
content (confirmed non-empty ahead of this plan). `~/.claude/settings.json`
and `~/.codex/hooks.json` on this machine already wire hook commands to the
old absolute path (`.../skills/agent-bridge/scripts/agent-bridge ...`).
`install-hooks.sh` reconciles existing entries in place rather than
duplicating them, per `specs/bridge`.

## Implementation

1. Confirm no agent has a message mid-write: `find ~/.agent-bridge -name '*.tmp' -o -name 'msg.*'` should be empty or only settled files.
2. `mv ~/.agent-bridge ~/.alter-bridge` (single atomic move, not copy+delete).
3. Verify: `diff -r` is not applicable post-move; instead confirm `ls ~/.alter-bridge/claude ~/.alter-bridge/codex ~/.alter-bridge/.archive` matches the pre-move listing captured in step 1's context.
4. Run `bash skills/alter-bridge/scripts/install-hooks.sh` (both runtimes, no argument) to reconcile `~/.claude/settings.json` and `~/.codex/hooks.json` to the new `alter-bridge` path.
5. Sanity check: `bash skills/alter-bridge/scripts/alter-bridge who` and `bash skills/alter-bridge/scripts/alter-bridge peek` both resolve against `~/.alter-bridge` with no `AGENT_BRIDGE_ROOT` override needed.

## Done when

- [ ] `~/.agent-bridge` no longer exists; `~/.alter-bridge` holds the same `claude/`, `codex/`, `.archive/` contents.
- [ ] `grep -n alter-bridge ~/.claude/settings.json ~/.codex/hooks.json` shows the reinstalled hook commands; `grep -n 'skills/agent-bridge' ~/.claude/settings.json ~/.codex/hooks.json` returns nothing.
- [ ] `alter-bridge who` runs clean with no env override.
