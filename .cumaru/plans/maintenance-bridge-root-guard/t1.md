# T1 — internal/broker.EnsureRoot with TDD tests

## What to do

Create package `internal/broker` with a function that resolves and
ensures the mailbox root directory exists, following TDD (red, verify red,
green, verify green).

## Design

```go
package broker

// EnsureRoot resolves the mailbox root — override if non-empty, else
// $home/.alter-bridge — and creates it if missing. home is passed
// explicitly (not read from os.Getenv) so the HOME=/ and empty-HOME
// guards are testable without mutating process environment.
func EnsureRoot(override, home string) (string, error) {
	...
}
```

Behavior:
- If `override` is non-empty, use it as the root path directly (no `$HOME`
  guard applies — an explicit override is the caller's own responsibility).
- Else, if `home` is empty or `/`, return an error (no directory created).
- Else root = `filepath.Join(home, ".alter-bridge")`.
- `os.MkdirAll(root, 0o755)`; wrap any error with the path in the message.
- Return the resolved root path on success.

## TDD cycle

1. Write `internal/broker/root_test.go` first, covering:
   - override path: creates and returns it, in a `t.TempDir()` subpath.
   - empty `home` and no override: returns an error, creates nothing.
   - `home = "/"` and no override: returns an error, creates nothing.
   - valid `home` (a `t.TempDir()`): creates `<home>/.alter-bridge`, returns that path.
   - root already exists: returns the path without error (call twice, or pre-create it).
2. Run `go test ./internal/broker/...` — confirm it fails to compile / fails (red) because `EnsureRoot` doesn't exist yet.
3. Implement `internal/broker/root.go` per the design above.
4. Run `go test ./internal/broker/...` — confirm all cases pass (green).
