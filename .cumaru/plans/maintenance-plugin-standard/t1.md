# T1 — Marketplace, manifests, bundled hooks, `install.sh`

## What to do

- `.claude-plugin/marketplace.json`: marketplace `alter-bridge` with one
  plugin `alter-bridge`, `"source": "./"`. Both CLIs read it.
- `hooks/hooks.json` (Claude default): `SessionStart` `watchpaths claude`,
  `UserPromptSubmit` `hook claude`, `FileChanged` matcher `.*__from_.*`
  `relay claude`, each `"${CLAUDE_PLUGIN_ROOT}/bin/alter-bridge" ...`,
  timeout 10.
- `hooks/codex.json`: `UserPromptSubmit` `"${PLUGIN_ROOT}/bin/alter-bridge" hook codex`,
  timeout 10, `additionalContextLimit` 0.
- Move root `plugin.json` to `.codex-plugin/plugin.json`, adding
  `"skills": "./skills/"`, `"hooks": "./hooks/codex.json"`, and `interface`.
  Without the manifest `hooks`, Codex would load `hooks/hooks.json` (Claude's).
- `install.sh`: `go/build.sh`, then marketplace add + plugin install on each
  CLI present.

## Done when

- [x] `claude plugin validate` passes for the marketplace and the manifest.
- [x] Scratch `CLAUDE_CONFIG_DIR` / `CODEX_HOME` installs satisfy AC1-AC5.
