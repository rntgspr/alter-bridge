# T1 — `mailbox.Purge` and `mailbox.ErrNoArchive`

## What to do

- Add `ErrNoArchive`, returned when `root/.archive` is missing or not a directory (bash `[ -d "$arch" ]`, which follows symlinks).
- Add `Purge(root) (int, error)`: for each entry of `root/.archive` whose name does not start with `.` and ends in `.md`, `os.Stat` it (follows symlinks, as bash `-e`); skip it when that fails or it is a directory; otherwise `os.Remove` it and count it. Return the count; a remove failure returns the count so far and the error.

## Context

Bash `purge()` (`alter-bridge:425`). `.archive/` is built inline in `mailbox.go` (`drain`, `archiveOne`), so the delete belongs next to `Archive`.
