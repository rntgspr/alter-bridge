# T2 — `broker.Resolve` and `purge` CLI wiring

## What to do

```
alter-bridge purge
```

- `broker.Resolve(override, home) (string, error)`: the current root choice and HOME guard of `EnsureRoot`, without creating anything; `EnsureRoot` calls it and then `MkdirAll`.
- `purge.go`: `purgeUsage` and `runPurge(args, root, stdout, stderr) int`.
  - Any argument: usage on stderr, exit 2.
  - `mailbox.Purge`: `ErrNoArchive` → `nothing to purge`; other error → stderr, exit 1; else `purged <n> archived message(s) from <root>/.archive`.
- `main.go`: `purge` case resolving the root with `broker.Resolve` (exit 1 on guard failure), not `setup()`, and a usage line.

## Context

Bash `purge()` (`alter-bridge:425`) ignores arguments and never creates `$ROOT`. `who` already skips `setup()` for the same reason; purge still needs the root, so the guard is shared through `broker.Resolve` rather than copied.
