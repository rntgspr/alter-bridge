# T2 — Root release workflow

## What to do

Write `.github/workflows/release.yml`, triggered on `push` of `v*` tags:

1. Check out the repo and set up Go from `go/go.mod`.
2. Run `go/release.sh <tag>`.
3. Create the GitHub Release and upload the zip.
4. Rewrite the `archive` source (`url`, `sha256`) of `alter-bridge` in
   `.claude-plugin/marketplace.json` and commit it to the default branch.

## Context

- GitHub only runs workflows from `.github/workflows/` at the repository root
  ([about workflows](https://docs.github.com/en/actions/writing-workflows/about-workflows)).
- The build logic stays in `go/`, so the workflow is a thin caller.
- The workflow needs `permissions: contents: write`.

## Implementation

- Prefer `gh release create` over third-party actions.
- Rewrite the JSON with `jq`.

## Done when

- [ ] `actionlint` (or a YAML lint when `actionlint` is unavailable) is clean.
- [ ] A dry run of the `jq` rewrite on a copy of `marketplace.json` yields the
  expected `url` and `sha256`.
