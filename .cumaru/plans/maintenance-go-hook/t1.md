# T1 — `hook` subcommand: payload, workspace gate, drain

## What to do

```
alter-bridge hook provider[:value] < payload.json
```

- `hook.go`: `hookUsage`, `hookEnv` (root, resolver, home, working dir, stdin, stdout, stderr) and `runHook(args, env) int`.
  - Exactly one argument; `-h`/`--help`, none, or extra → usage, exit 2. A bare known provider or a `provider:value` (`address.Parse`); anything else → error, exit 2.
  - Decode stdin; session id = first non-empty string of `session_id`, `thread_id`, `threadId`; `cwd` string. Decode failures leave both empty.
  - Scope dir = `cwd` (joined onto the working dir when relative, cleaned) if it is an existing directory, else the working dir. Outside `home/agentic-workspace` (equal or below) → exit 0, silent.
  - Bare provider with no session id → exit 0, silent.
  - `Resolver.Slug` then `mailbox.Drain(root, box, true, stdout)`; errors → stderr, exit 1.
- `main.go`: `hook` case resolving the root with `broker.Resolve` (never created), `session.NewResolver(home)`, `os.Getwd`, and a usage line.

## Context

Bash `hook()` (`alter-bridge:278`). Identity follows the go-send model (see the plan's Overview). The drain is `mailbox.Drain`, shared with `inbox`.

## Implementation

1. Tests first (in-process, temp root, fake stores): bare provider drains the session-name mailbox from `session_id`, and from `thread_id`/`threadId`; explicit address ignores the payload id; outside-workspace `cwd` and nonexistent `cwd` falling back to an outside working dir are silent no-ops; a nonexistent `cwd` with a workspace working dir drains; empty/garbage payload and missing id are silent exit 0; missing mailbox creates neither root nor mailbox; usage errors exit 2 untouched.
2. Watch them fail (undefined `runHook`), then implement and wire.
