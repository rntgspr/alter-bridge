# T2 — `who` CLI wiring

## What to do

```
alter-bridge who
```

- `who.go`: `whoEnv{Claude func() ([]session.Agent, error); Codex session.Store; Stdout, Stderr io.Writer}` and `runWho(args, env) int`.
- Claude rows: skip empty names; `fmt.Fprintf("%-26s %s  %s\n", "claude:"+slug, id, cwd)`.
- Codex rows: first 10 store sessions, skip empty names; `fmt.Fprintf("%-26s %s\n", "codex:"+slug, id)`.
- A provider error omits its rows; exit 0. Any argument → usage on stderr, exit 2.
- `main.go`: `who` case wired from `HOME` only — `session.ClaudeAgents(home)` and `session.NewResolver(home).Stores["codex"]` — without `setup()`, so the mailbox root is never created.

## Context

Bash reference: `who()` (`alter-bridge:439`). Slugs are ASCII, so Go's rune-based `%-26s` padding equals bash's byte padding.

## Implementation

1. Tests first (`who_test.go`, in-process, fake funcs): both providers in bash format and order; unnamed rows skipped; only the first 10 Codex rows considered; each provider's error omits only its rows with exit 0 and empty stderr; arguments → exit 2.
2. Watch them fail (undefined `runWho`), then implement and wire the dispatch case and usage line.
