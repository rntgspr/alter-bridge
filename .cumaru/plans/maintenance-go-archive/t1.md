# T1 — `mailbox.Archive` and `mailbox.Boxes`

- Move `Drain`'s loop into a private `drain(root, box, archive, w) (int, error)` that counts the messages it handles and skips reading/printing when `w` is nil; `Drain` keeps its signature and calls it.

- Add `Boxes(root) ([]address.Address, error)`: every directory `<root>/<provider>/<slug>` whose provider and slug names do not start with `.`, in byte order; a missing root yields none.
