# T2 — `archive` CLI wiring

## What to do

```
alter-bridge archive [provider:value]
```

- `archive.go`: `archiveUsage` and `runArchive(args, env inboxEnv) int`.
  - One address: `address.Parse` (exit 2), `Resolver.Slug` (exit 1), `mailbox.Archive`, print `archived <n> from <arg>`.
  - No address: `mailbox.Boxes`, `mailbox.Archive` each, print non-zero lines, then `total: <sum>`.
  - More than one argument or `-h`/`--help`: usage on stderr, exit 2. Filesystem errors: exit 1.
- `main.go`: `archive` dispatch case via `setup()` and a usage line.

## Context

Bash reference `archive()` (`alter-bridge:401`). `runDrain` requires exactly one address, so `archive` has its own argument handling but reuses `inboxEnv`, `address.Parse`, and the resolver.
