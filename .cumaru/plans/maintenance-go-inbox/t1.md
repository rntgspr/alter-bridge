# T1 — Mailbox drain helper

## What to do

Create `internal/mailbox` with:

- `Drain(root string, box address.Address, archive bool, w io.Writer) error` — `box.Value` is an already resolved slug. Lists `*.md` regular files (no dotfiles, no directories) in `<root>/<provider>/<slug>/` in byte order; for each, when `archive` is set, moves it into `<root>/.archive/` under the bash archived name first; then writes the header, content, and trailing newline to `w`. A missing mailbox directory is not an error.

Export the random id generator from `internal/message` (`RandomID`) so the collision suffix reuses it instead of duplicating it.

## Context

Bash reference: `drain` (`alter-bridge:229-270`). Archived name: `prefix="${base%__*}"; id="${base##*__}"; dest="$arch/${prefix}__to_${sp}_${ss}__${id}"`, then `while [ -e "$dest" ]; do dest="${dest%.md}.$(rand_id).md"; done`. The header uses the original base name, the content is read from the archived path.
