# T2 — `inbox` CLI wiring

## What to do

```
alter-bridge inbox <provider:value>
```

- Address required; missing, extra, or malformed → usage on stderr, exit 2.
- Resolve with `session.Resolver.Slug`; ambiguous or empty slug → stderr, exit 1, nothing moved.
- `mailbox.Drain(root, box, true, stdout)`; error → stderr, exit 1; else exit 0.
- Root and resolver built exactly as for `send` in `main.go` (no second copy of that setup).

## Context

Bash reference: `inbox() { drain yes "$@"; }` (`alter-bridge:272`). The Go identity model (`maintenance-go-send`) forbids an environment fallback for the address.

## Implementation

1. Tests first (in-process, temp root, fake stores): happy path prints and archives; id resolves to the name mailbox; missing address exits 2; ambiguous name exits 1 with nothing moved; empty mailbox exits 0 silently.
2. Implement `runInbox` and the dispatch case.
