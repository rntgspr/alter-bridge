# T4 — `send` CLI wiring

## What to do

Replace the hello-world `main.go` with subcommand dispatch and implement:

```
alter-bridge send <to> --from <provider:value> [--type T] [--thread ID] [--in-reply-to MSGID] [body_file|-]
```

- `--from` required; missing → usage on stderr, exit 2.
- `<to>` and `--from` parsed with T1, resolved to slugs with T2. On `AmbiguousError`, print the candidate ids on stderr and exit non-zero without writing.
- Body from `body_file`, or stdin when omitted or `-`.
- Root from `broker.EnsureRoot(os.Getenv("ALTER_BRIDGE_ROOT"), os.Getenv("HOME"))` — the only environment reads, neither decides identity.
- Deliver with T3, print the path, exit 0.

## Context

Bash reference: `usage` and `send` argument loop (`alter-bridge:126-178`). Use the standard `flag` package; no CLI framework dependency. Flags may appear after `<to>` as in bash, so parse `<to>` first and hand the rest to a `flag.FlagSet`, collecting the positional body argument.

1. Tests first (run the command in-process against a temp root): happy path prints a path that exists; missing `--from` exits 2; bad `--type` exits non-zero with nothing written; stdin body; `-` body.
2. Implement dispatch and `send`.
