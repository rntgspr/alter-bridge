# T3 — Message file write

## What to do

Create `internal/message` with:

- `Type` validation for `message | question | result | ack`.
- `Deliver(root string, m Message, body io.Reader) (string, error)` — writes frontmatter + body to a temp file in `<root>/.tmp/`, renames into `<root>/<to.provider>/<to.slug>/<ts>__from_<from.provider>_<from.slug>__<msgid>.md`, regenerating `msgid` on collision; returns the destination path.

## Context

Bash reference: `now_ts`, `rand_id`, and the body of `send` (`alter-bridge:12-22`, `184-211`). Field order: `from`, `to`, `ts`, `msgid`, `thread?`, `in_reply_to?`, `type`, then a blank line and the body. `inbox`/`peek` will parse this filename layout, so keep it exact.

## Implementation

1. Tests first: frontmatter bytes for a full and a minimal message; invalid type rejected with nothing on disk; filename matches the regex `^\d{8}T\d{6}\.\d{3}Z__from_[^_]+_.+__[0-9a-f]{8}\.md$`; no file left in `.tmp/` after success; collision path regenerates (inject the id generator).
2. Timestamp: UTC, millisecond precision, `20060102T150405.000Z` layout.
3. `msgid`: 4 bytes from `crypto/rand`, hex.
4. `os.Rename` within the same root, so it stays atomic on one filesystem.
