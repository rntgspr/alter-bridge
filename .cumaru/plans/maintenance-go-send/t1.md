# T1 — Address parsing and slugify

## What to do

Create `internal/address` with:

- `Parse(s string) (Address, error)` — strips a leading `#`, splits on the first `:`, validates the provider against `claude | codex | opencode`, rejects empty halves.
- `Slugify(s string) string` — byte-for-byte equivalent of the bash `slugify`.
- `Address{Provider, Value string}` with a `String()` returning `provider:value`.

## Context

Bash reference: `parse_addr`, `check_addr`, `slugify` in `skills/alter-bridge/scripts/alter-bridge:24-46`. Bash accepts any provider; Go restricts to the three known ones (plan AC "Addressing").

## Implementation

1. Table-driven tests first: `#codex:bridge`, `claude:pikachu`, `opencode:x`, `foo:bar` (error), `claude:` (error), `:x` (error), `claude:a:b` (value `a:b`).
2. Slugify tests: `workspace/fe` → `workspace-fe`, `  Foo  Bar ` → `foo-bar`, `a--b` → `a-b`, `ÁB` → matches bash output for the same input (verify by running bash `slugify`).
