# T2 — Build to bin/ and gitignore it

## What to do

Build the binary into `bin/`, verify it runs, and keep `bin/` out of
version control.

## Context

Repo has no `.gitignore` yet (confirmed absent). `bin/` is a build output,
not source, and should never be committed.

## Implementation

1. `go build -o bin/alter-bridge ./cmd/alter-bridge`.
2. `./bin/alter-bridge` and confirm it prints `hello world` and exits `0`.
3. Create `.gitignore` at repo root with a `bin/` entry (start the file if none exists yet).

## Done when

- [ ] `bin/alter-bridge` exists and `./bin/alter-bridge` prints `hello world`, exit code `0`.
- [ ] `git status --porcelain` does not list `bin/alter-bridge` as untracked after the `.gitignore` change.
