# T1 — Init go.mod and hello-world main

## What to do

Create the Go module and a minimal `main` package that prints `hello world`.

## Context

Repo root has no `go.mod` yet. Module path should match the repo's GitHub
remote, already repointed to `git@github.com:rntgspr/alter-bridge.git`, so
the module path is `github.com/rntgspr/alter-bridge`.

## Implementation

1. `go mod init github.com/rntgspr/alter-bridge`.
2. Create `cmd/alter-bridge/main.go`:
   ```go
   package main

   import "fmt"

   func main() {
       fmt.Println("hello world")
   }
   ```
3. `go run ./cmd/alter-bridge` and confirm it prints `hello world`.

## Done when

- [ ] `go.mod` exists at repo root with module `github.com/rntgspr/alter-bridge`.
- [ ] `go run ./cmd/alter-bridge` prints `hello world`.
